# House Prices ML

End-to-end regression pipeline on Kaggle's House Prices: Advanced Regression Techniques dataset, progressing from a baseline model toward a tuned, explainable, and eventually deployed pipeline.

## Structure

- `docs/phase0.md`, EDA, missing value handling, outlier investigation, and baseline model comparison (Linear Regression, Random Forest, XGBoost)
- `docs/phase1.md`, feature engineering, cross-validation, hyperparameter tuning, and explainability (in progress)
- `notebooks/`, working notebooks per phase
- `data/`, raw dataset (gitignored, not committed)

## Current status

Phase 0 complete. Best baseline so far: Linear Regression, RMSE 0.1292 on log-transformed SalePrice. See `docs/phase0.md` for full details.

Phase 1 in progress.
